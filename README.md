# Hilbert’s fourteenth problem

This repository contains a Lean 4 formalization of Kuroda’s explicit
three-variable counterexample in “Hilbert’s fourteenth problem and field
modifications” by Shigeru Kuroda.

The Lean formalization was generated by Codex under the guidance of Evgeny Obukhov.

[Read the paper](https://arxiv.org/abs/1803.08002v1)

## Counterexample

Inside ℂ(x,y,z), let

$$
L=\mathbb C\left(x^5y+x^{-2},\;x^4y-x^{-2}+x^{-3},\;z+x^{-1}\right).
$$

We prove that $L\cap\mathbb C[x,y,z]$ is not finitely generated as a
$\mathbb C$-algebra, giving a negative answer to Hilbert’s fourteenth problem.
The [main theorem](Hilbert14/Theorem.lean) also applies to every field
of characteristic zero.

## Building the formalization

The project uses Lean 4.34.1, Mathlib, and Lake. With
[elan](https://github.com/leanprover/elan) installed, fetch the Mathlib cache
and build the formalization with:

```sh
lake exe cache get
lake build
```
